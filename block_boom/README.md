# Block Boom

Головоломка с блоками для Android на Flutter: поле 8×8, три фигуры в лотке.
Перетаскиваешь фигуры на поле, собираешь целые строки и столбцы, они взрываются.
Ходов нет — игра окончена.

## Что внутри

- **Комбо.** Каждая собранная линия подряд увеличивает множитель. Серия сгорает,
  если три хода подряд ничего не собрать; сколько ходов осталось, показывают точки
  на плашке «КОМБО».
- **Очки:** +1 за клетку, за линии `10 · n(n+1)/2 × комбо`, +300 за чистое поле.
- **Честная раздача.** В начале партии каждый набор из трёх фигур гарантированно
  можно поставить, и часто среди них есть фигура, которая соберёт линию. С ростом
  счёта крупных фигур больше, а помощи меньше.
- **Подсказки при перетаскивании:** тень на поле, а линии, которые соберутся,
  заранее перекрашиваются и подсвечиваются.
- **Эффекты:** разлёт осколков, вспышки, кольца, тряска экрана, конфетти, надписи
  «Хорошо! / Отлично! / Супер! / Невероятно!», звуки колокольчиков, которые
  становятся выше с каждым шагом комбо, вибрация.
- **Второй шанс** один раз за партию: убирает две самые заполненные строки и два
  столбца. Если до рекорда осталось немного, игра об этом скажет.
- **Прогресс:** опыт = набранные очки, уровни и звания, 6 тем оформления
  («Классика», «Неон», «Желейки», «Океан», «Лава», «Сокровища»), которые
  открываются по уровням. У каждой темы своя форма блоков.
- Партия сохраняется после каждого хода, можно закрыть игру и продолжить.

## Сборка

```bash
flutter pub get
flutter test
flutter build apk --release   # build/app/outputs/flutter-apk/app-release.apk
```

APK подписан debug-ключом: для установки вручную этого достаточно. Для Google Play
нужен свой ключ (см. `android/app/build.gradle.kts`).

## Ресурсы

Звуки и иконка сгенерированы скриптами, чужих файлов нет:

```bash
python3 tool/gen_sfx.py    # assets/sfx/*.wav (нужен numpy)
python3 tool/gen_icon.py   # иконки в android/app/src/main/res (нужен Pillow)
```

Шрифт — [Russo One](https://fonts.google.com/specimen/Russo+One), лицензия OFL
(`assets/fonts/OFL.txt`).

## Код

- `lib/game/` — логика без Flutter: поле, фигуры, раздача, очки, сохранение, уровни.
- `lib/ui/` — экраны и отрисовка: блоки рисуются на `Canvas` и кэшируются
  картинками, эффекты считаются в собственном цикле на `Ticker`.
- `lib/audio/sfx.dart` — звуки (не забирают аудиофокус, музыка пользователя не
  прерывается) и вибрация.
