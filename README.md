# Расписание КОГПК

Android-приложение: расписание групп и преподавателей, электронный журнал по
номеру зачётки, виджеты на главный экран (2×2 и 4×2).

Flutter. Данные — из кэша Telegram-бота расписания через API на сервере.

## Игра

В папке [`block_boom/`](block_boom/) лежит отдельный проект: игра-головоломка Block Boom (Flutter, Android).
